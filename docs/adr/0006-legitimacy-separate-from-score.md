# Posting legitimacy (Block G) is separate from the 1–5 Score

The Evaluation produces a 1–5 fit Score from blocks A–F (Match, North Star, Comp,
Cultural signals, Red flags, Global). Whether the Posting is a real, active opening is
assessed separately in Block G as a qualitative **Legitimacy tier** (High Confidence /
Proceed with Caution / Suspicious) that does not feed the numeric Score.

We kept these axes orthogonal because they answer different questions: "is this a great
role for me?" vs "is this posting even real?" Folding legitimacy into the Score would let
a perfect-fit role and a Ghost posting average into the same middling number, hiding both
signals. Separated, a 4.6/5 Suspicious Posting reads correctly — strong match, verify
before spending effort. The trade-off is that downstream sorting/filtering must consult
two fields instead of one, and the user has to weigh them together rather than trusting a
single ranking.
